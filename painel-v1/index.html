tuttibom-ops — Painel v1

Esboço só leitura. Só o Muse edita e atualiza este painel. Sem botão de publicar, responder ou apagar. Sem dado de comprador.

Dados mockados: todos os números abaixo são de exemplo, para validar layout e leitura. Não são dados reais da loja, de uma conta ou de um comprador.

Mapa — hierarquia e checkpoints

Guardrails (acima de tudo) ↓
Check de acesso Android: rede → SSH → ADB → tela acordada → app em foco ↓
Skills de setor: Marketplace · Publicações · Interações ↓
Decisão Jev (System 1, com limiar → humano) + Geração Muse / NotebookLM (System 2) ↓
Execução: conector da Página (futuro) ou ADB da conta pessoal (hoje) ↓
Auditoria → Painel (só leitura)
Checkpoint humano em: preço, texto e mídia exatos, identidade, exceções.
