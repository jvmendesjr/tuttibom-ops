# Catálogo

Um arquivo por produto. Copie `produto-impressao-3d.md` ou
`produto-fita-cetim.md` e preencha só com dados reais. Campo vazio
significa "não sei ainda" — e o agente pergunta, não inventa.

Fotos curadas vão para `catalogo/fotos/` (criar quando houver o
primeiro produto real). Fotos brutas não vão para o repositório.
