# Prompt de entrada — agente TuttiBom OPS

Entregue o [diretório de entrada](../agent-entry/tuttibom-ops/) ou o
[`AGENTS.md`](../agent-entry/tuttibom-ops/AGENTS.md) ao agente. O arquivo é
o mesmo para todo cliente: área, funções e skills vêm do manifesto.
O operador configura o MCP antes da entrega. Endereço e credencial ficam
na configuração do cliente, nunca no diretório compartilhado ou na conversa.

Se a sessão não abrir o `AGENTS.md` automaticamente, indique o arquivo:

```text
Leia o AGENTS.md do TuttiBom Ops e siga as instruções de entrada.
```

Para um objetivo específico, acrescente só a tarefa. Não copie procedimentos
para o prompt. A autorização do papel não aprova nenhuma saída ou compromisso.
