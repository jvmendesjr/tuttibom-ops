# Prompt do Ops por área

Use o [prompt único de entrada](../prompt-entrada-agente-ops.md).
Acrescente só o objetivo da tarefa, se necessário. Área, funções e
skills vêm do manifesto; não inclua IDs, referência ou credencial no prompt.

Já disponíveis no laboratório: triagem de Atendimento, preparação e
resposta simulada quando autorizadas, e consulta de preço de catálogo.
Para saber o que ainda não pode ser atribuído, consulte o
[inventário Core e Ops](mcp-core-e-ops.md). O setor 08 usa o Core.
