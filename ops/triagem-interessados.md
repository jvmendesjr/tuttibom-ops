# CRM dos interessados — triagem e acompanhamento

Ver `docs/pesquisa-interacao-crm.md` e
`skills/crm-interessados/SKILL.md`. Uma linha por negociação, não
por pessoa. Sem telefone, email ou endereço neste arquivo: só o
mínimo operacional. O dado pessoal fica na thread do
Messenger/Marketplace.

Estágios: Novo → Contatado → Qualificado → Proposta enviada →
Produção / Retirada → Fechado / Perdido / Adormecido.

| Data 1º contato | Origem / anúncio | Produto | Personalização | Valor est. (catálogo) | Cidade / retirada | Estágio | Última interação | Próxima ação | Data follow-up | Encaminhado? | Resposta aprovada/enviada? | Motivo de perda |
|-----------------|------------------|---------|----------------|-----------------------|-------------------|---------|------------------|--------------|----------------|--------------|----------------------------|-----------------|
|                 |                  |         |                |                       |                   |         |                  |              |                |              |                            |                 |

Regras: nada enviado sem aprovação do texto exato; golpe suspeito
vai direto para o usuário, sem resposta; todo negócio aberto tem
próxima ação e data; follow-up em 1 dia (sem retorno), 2–3 dias
(após proposta), 7 dias → Adormecido, no máximo 2 follow-ups sem
resposta nova.
